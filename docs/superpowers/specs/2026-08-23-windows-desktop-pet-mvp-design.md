# Windows 데스크톱 펫 MVP 제품·기술 명세

문서 버전: 1.0
작성일: 2026-08-23
대상 릴리스: MVP
대상 플랫폼: Windows 11 64비트
기술 기준: 기존 Tauri 2 + Rust 앱 확장

## 1. 문서 목적

이 문서는 기존 트레이 기반 데스크톱 캐릭터 앱을 Windows 11 전용 투명 오버레이 펫으로 확장하는 MVP의 제품 범위, 동작 규칙, 안전장치, 구조와 완료 조건을 정의한다.

제품은 Desktop Goose처럼 화면을 돌아다니고 가벼운 장난을 치는 펫 경험과, 뽀모도로 집중 세션 중 사용자가 지정한 방해 대상을 제지하는 생산성 기능을 결합한다.

펫 원화와 애니메이션 자산은 제작 중이다. 따라서 MVP 구현은 특정 캐릭터 그림에 의존하지 않고 교체 가능한 캐릭터 팩을 사용한다.

## 2. 제품 정의

### 2.1 한 문장 정의

화면 위를 돌아다니며 장난을 치고, 집중 시간에는 방해 앱을 발로 차서 최소화하는 Windows 11 데스크톱 펫.

### 2.2 핵심 가치

1. **살아 있는 동반자:** 펫이 걷고 반응하며 예측하기 어려운 작은 행동을 한다.
2. **유쾌한 집중 보조:** 강압적인 차단 화면 대신 캐릭터 행동으로 집중 복귀를 유도한다.
3. **사용자 통제:** 감지 대상, 개입 강도, 빈도와 타이머 시간을 사용자가 정한다.
4. **안전한 장난:** 프로그램을 임의 실행하거나 파일을 변경하지 않으며 언제든 즉시 중지할 수 있다.
5. **확장 가능한 캐릭터:** 완성되는 펫 자산과 추후 이스터에그 캐릭터를 코드 변경을 최소화해 추가한다.

## 3. MVP 범위

### 3.1 반드시 포함하는 기능

- Windows 시작 후 트레이 상주 및 투명 펫 오버레이 표시
- 화면 안에서 걷기, 대기, 방향 전환과 다중 모니터 경계 처리
- 일정 확률로 마우스 커서 추적
- 펫 클릭, 반복 클릭, 마우스 드래그와 놓기
- 드래그 후 빠르게 놓으면 앵그리버드처럼 관성으로 날아가는 동작
- 춤추기 애니메이션
- 말풍선 대사
  - `데프콘 가자`
  - 집중 중 비활동 판정 시 `데프콘 안 갈 거야?`
  - 무작위 아무 말 뒤 `미안하다`
- WinDbg 또는 Hyper-V를 상징하는 이미지 카드를 끌고 와 화면에 놓기
- 클릭 횟수 기반 이스터에그 1종
- 뽀모도로 집중·휴식 타이머
- 사용자 지정 방해 앱·사이트 규칙
- 집중 중 방해 대상 감지 시 이동, 발차기 애니메이션, 대상 창 최소화
- 집중 중 장시간 비활동 시 `미식이 발차기` 연출
- 기본 펫 꾸미기 구조와 액세서리 레이어 켜기/끄기
- 행동별 활성화, 빈도와 방해 강도 설정
- 트레이 메뉴와 긴급 중지 단축키
- 모든 설정의 로컬 저장

### 3.2 MVP에서 제외하는 기능

- macOS, Linux와 Windows 10 지원
- 계정, 클라우드 동기화, 온라인 상점과 분석 SDK
- 임의 프로그램 실행, 파일 생성·이동·삭제
- 브라우저 확장 프로그램을 이용한 URL 감시
- 실제 창을 화면 밖으로 밀거나 크기를 바꾸는 기능
- 강제 종료, 네트워크 차단 또는 사이트 접속 자체 차단
- 사용자가 직접 새 캐릭터 팩을 제작하는 편집기
- 온라인에서 밈이나 이미지를 자동 다운로드하는 기능
- `네모` 캐릭터의 구체적인 등장 조건과 연출

`네모`는 후속 이스터에그 캐릭터로 분리한다. MVP에는 새로운 캐릭터 이벤트를 등록할 수 있는 확장 인터페이스만 둔다.

## 4. 핵심 사용자 흐름

### 4.1 최초 실행

1. 앱이 시스템 트레이에 나타난다.
2. 펫이 현재 주 모니터의 작업 영역 안에 표시된다.
3. 최초 실행 안내에서 다음 항목을 보여준다.
   - 펫 드래그 방법
   - 뽀모도로 시작 방법
   - 방해 대상 설정 위치
   - 긴급 중지 단축키
4. 기본값에서는 창 최소화 개입이 꺼져 있다.
5. 사용자가 방해 대상을 한 개 이상 등록하고 개입 기능을 명시적으로 켜야 창 최소화가 활성화된다.

### 4.2 평상시 펫

1. 펫은 Idle, Walk, Chase, Dance, Speak, CarryCard 중 하나의 행동을 수행한다.
2. 일반 행동은 서로 겹치지 않으며 행동 엔진이 한 번에 하나만 선택한다.
3. 사용자가 펫을 잡으면 현재 자동 행동을 취소하고 Dragged 상태가 우선한다.
4. 놓는 속도가 임계값 미만이면 놓은 위치에 착지한다.
5. 임계값 이상이면 Thrown 상태로 전환해 관성, 중력과 화면 경계 반사를 적용한다.
6. 날아가는 펫은 최대 3초 안에 감속해 착지하고 Walk 또는 Idle로 복귀한다.

### 4.3 집중 세션

1. 사용자가 트레이 또는 타이머 창에서 집중 세션을 시작한다.
2. 앱은 사용자가 등록한 방해 대상 규칙과 현재 전경 창을 비교한다.
3. 일치하는 창이 설정된 유예 시간 동안 계속 활성화되면 개입 이벤트를 예약한다.
4. 펫이 대상 창의 가까운 화면 가장자리로 이동한다.
5. 1초 이상 경고 말풍선을 표시해 사용자가 취소할 기회를 준다.
6. 취소되지 않으면 펫이 발차기 애니메이션을 재생한다.
7. 발차기 충돌 프레임에서 대상 창을 최소화한다.
8. 같은 대상에는 쿨다운을 적용해 반복 최소화를 방지한다.
9. 휴식 세션, 일시정지 또는 집중 세션 종료 시 감지와 창 최소화를 즉시 중지한다.

## 5. 펫 행동 명세

### 5.1 행동 상태

| 상태 | 진입 조건 | 종료 조건 | 우선순위 |
|---|---|---|---:|
| Idle | 다른 행동이 없음 | 다음 행동 선택 | 10 |
| Walk | 임의 목적지 선택 | 목적지 도착 또는 중단 | 20 |
| ChaseCursor | 추적 이벤트 발생 | 제한 시간, 거리 도달, 사용자 입력 | 30 |
| Speak | 대사 이벤트 발생 | 말풍선 표시 종료 | 40 |
| Dance | 춤 이벤트 발생 | 1회 애니메이션 완료 | 40 |
| CarryCard | 카드 이벤트 발생 | 카드 배치 완료 | 50 |
| FocusWarning | 비활동 또는 방해 대상 감지 | 취소 또는 발차기 전환 | 70 |
| Kick | 경고 후 개입 실행 | 애니메이션과 최소화 완료 | 80 |
| Dragged | 사용자가 펫을 잡음 | 마우스 버튼 해제 | 100 |
| Thrown | 빠른 속도로 놓음 | 착지 또는 3초 경과 | 90 |

- 더 높은 우선순위의 행동은 낮은 행동을 중단할 수 있다.
- Dragged와 Thrown 중에는 창 최소화가 실행되지 않는다.
- 집중 세션 종료 이벤트는 모든 FocusWarning과 Kick 예약보다 우선한다.

### 5.2 이동

- 펫의 기준 좌표는 가상 데스크톱 좌표계를 사용한다.
- 작업표시줄을 제외한 각 모니터 작업 영역 안에서 목적지를 선택한다.
- 모니터 사이에 연결된 이동 경로가 없으면 순간 이동하지 않고 현재 모니터 안에서 새 목적지를 고른다.
- 펫은 최소 24px 이상 화면 안에 남아야 한다.
- 기본 이동 속도, 추적 확률과 최대 추적 시간은 설정에서 조정할 수 있다.

### 5.3 마우스 상호작용

- 펫의 불투명 영역과 작은 상호작용 여백만 마우스 입력을 받는다.
- 그 외 투명 영역의 입력은 아래 창으로 전달한다.
- 단일 클릭은 짧은 반응 애니메이션을 실행하고 클릭 카운터를 증가시킨다.
- 빠른 연속 클릭은 일반 대사와 별도의 반응을 사용할 수 있다.
- 드래그 중 최근 포인터 좌표와 시간을 사용해 놓는 순간의 속도를 계산한다.
- 던지기 속도와 화면 경계 반발 계수는 상한을 둬 펫이 영구히 움직이지 않게 한다.

### 5.4 대사

- 대사는 화면을 가리지 않는 작은 말풍선으로 2~4초 표시한다.
- 같은 대사는 기본 10분 쿨다운을 적용한다.
- `데프콘 가자`는 일반 랜덤 대사 이벤트로 사용한다.
- `데프콘 안 갈 거야?`는 집중 세션의 비활동 경고에만 사용한다.
- 아무 말 이벤트는 등록된 짧은 문장 하나를 먼저 표시하고 0.5~1.5초 뒤 `미안하다`를 표시한다.
- 대사 문구와 기능별 사용 여부는 설정 파일에서 관리한다.

### 5.5 이미지 카드

- 펫은 WinDbg 또는 Hyper-V 테마 카드 중 하나를 선택해 화면 가장자리에서 끌고 온다.
- 카드는 정적 이미지와 짧은 문구로 구성되며 실행 파일 링크나 실행 동작을 포함하지 않는다.
- 카드를 클릭하면 프로그램을 실행하지 않고 카드 닫기 또는 위치 이동만 가능하다.
- 카드는 기본 15초 뒤 자동으로 사라지며 사용자가 즉시 닫을 수 있다.
- 동시에 표시되는 카드는 최대 1개다.
- 공식 로고를 번들할 때는 재배포 권리를 확인한다. 권리가 불명확하면 자체 제작한 개발 도구·가상화 테마 아이콘을 사용한다.

### 5.6 클릭 이스터에그

- 한 세션에서 펫을 10초 안에 7회 클릭하면 이스터에그를 실행한다.
- 이스터에그는 특수 표정, 춤과 대사로 구성하며 시스템 설정이나 파일을 변경하지 않는다.
- 실행 후 30분 쿨다운을 적용한다.
- 구체 자산이 준비되지 않으면 기본 펫의 기존 프레임 조합으로 표현할 수 있어야 한다.

## 6. 뽀모도로 명세

### 6.1 기본값

| 항목 | 기본값 | 허용 범위 |
|---|---:|---:|
| 집중 시간 | 25분 | 1~120분 |
| 짧은 휴식 | 5분 | 1~60분 |
| 긴 휴식 | 15분 | 1~90분 |
| 긴 휴식 주기 | 집중 4회 후 | 1~10회 |
| 자동 휴식 시작 | 꺼짐 | 켜짐/꺼짐 |
| 자동 집중 시작 | 꺼짐 | 켜짐/꺼짐 |

### 6.2 상태

`Stopped → Focus → ShortBreak/LongBreak → Focus` 순환을 기본으로 하며 각 실행 상태에서 Paused로 전환할 수 있다.

- 앱 재시작 시 실행 중이던 세션은 자동 재개하지 않고 복구 안내를 표시한다.
- 시스템 절전 중에도 종료 시각을 기준으로 남은 시간을 계산한다.
- 절전 중 세션이 끝났다면 복귀 후 완료 알림만 한 번 표시한다.
- 사용자가 시스템 시간을 변경해도 단조 시간 기준 경과값과 비교해 비정상적인 음수 시간을 방지한다.
- 집중 세션 완료 횟수는 로컬에 일 단위로 저장하되 창 제목과 사용 앱 기록은 저장하지 않는다.

### 6.3 타이머 UI

- 트레이 메뉴에서 현재 상태와 남은 시간을 확인한다.
- 작은 타이머 창에서 시작, 일시정지, 재개, 건너뛰기와 중지를 제공한다.
- 세션 전환 시 Windows 알림과 펫 애니메이션을 함께 사용한다.
- 알림음은 기본 꺼짐이며 사용자가 켤 수 있다.

## 7. 방해 대상과 비활동 판정

### 7.1 방해 대상 규칙

사용자는 다음 조건을 하나 이상 조합해 규칙을 만든다.

- 실행 파일명: 예 `chrome.exe`, `msedge.exe`
- 창 제목에 포함되는 문자열: 예 `YouTube`
- 규칙 이름과 사용 여부
- 감지 유예 시간: 5초~10분
- 최소화 후 쿨다운: 30초~60분

MVP는 브라우저 주소 표시줄이나 방문 기록에 접근하지 않는다. 사이트 감지는 브라우저 창 제목에 사이트명이 포함되는 경우에만 동작하므로 제목이 바뀌거나 숨겨지면 감지하지 못할 수 있다. 설정 화면에 이 제한을 명시한다.

### 7.2 비활동 판정

- 비활동 기준은 사용자가 설정한다.
- 기준 시간 범위는 1~60분이며 기본값은 10분이다.
- Windows의 마지막 입력 시간을 사용해 키보드·마우스 입력이 없는 시간을 계산한다.
- 비활동 시간 원본과 입력 내용은 저장하지 않는다.
- 비활동 경고는 `데프콘 안 갈 거야?` 말풍선 후 `미식이 발차기` 애니메이션을 실행한다.
- 비활동 발차기는 사용자나 다른 창에 입력을 보내지 않는 순수 애니메이션이다.
- 비활동 경고는 집중 세션마다 최대 2회, 최소 10분 간격으로 제한한다.

### 7.3 창 최소화 절차

1. 현재 전경 창 핸들과 프로세스 ID를 얻는다.
2. 사용자가 등록한 활성 규칙과 대조한다.
3. 유예 시간 동안 동일한 창이 전경인지 확인한다.
4. 보호 대상 여부를 다시 검사한다.
5. 펫 이동과 경고를 실행한다.
6. 실행 직전에 전경 창과 규칙 일치를 다시 확인한다.
7. 일치하면 `ShowWindow(SW_MINIMIZE)`에 해당하는 안전한 Windows API를 호출한다.
8. 실패하면 한 번만 기록하고 반복 호출하지 않는다.

### 7.4 보호 대상

다음 창은 기본적으로 최소화하지 않는다.

- 앱 자신의 설정·타이머·오버레이 창
- Windows 보안 화면과 UAC
- 잠금 화면, 작업 관리자와 시스템 셸의 핵심 창
- 파일 저장/열기 대화상자
- 전체화면 게임과 독점 전체화면 앱
- 화상회의 앱과 원격 데스크톱 앱
- 제목이나 프로세스를 확인할 수 없는 높은 권한 창

사용자는 보호 목록에 앱을 추가할 수 있지만 기본 보호 항목은 해제할 수 없다.

## 8. 설정 명세

### 8.1 사용자 설정

- 펫 표시, 항상 위, Windows 시작 시 실행
- 일반 행동 활성화와 빈도: 낮음/보통/높음
- 커서 추적, 춤, 대사, 이미지 카드 각각 켜기/끄기
- 펫 크기: 50~200%
- 이동 속도와 던지기 감도
- 사용 가능한 액세서리 레이어 선택
- 뽀모도로 시간과 자동 시작 옵션
- 방해 대상 규칙 추가·수정·삭제·일시 비활성화
- 비활동 기준 시간과 경고 사용 여부
- 창 최소화 개입 사용 여부와 경고 시간
- 알림음과 Windows 알림 사용 여부
- 긴급 중지 단축키

### 8.2 기본 안전값

- 창 최소화 개입: 꺼짐
- 방해 대상 규칙: 없음
- 비활동 경고: 꺼짐
- 일반 장난 빈도: 낮음
- 이미지 카드: 켜짐
- 자동 시작: 꺼짐
- 긴급 중지 단축키: `Ctrl+Shift+F12`

### 8.3 긴급 중지

- 단축키를 누르면 펫 오버레이, 카드, 대사와 모든 창 개입을 즉시 숨긴다.
- 실행 중인 타이머는 일시정지한다.
- 트레이 아이콘과 `펫 다시 시작` 메뉴는 유지한다.
- 단축키 등록에 실패하면 시작 시 사용자에게 알리고 대체 단축키를 설정하게 한다.

## 9. 캐릭터와 자산 규격

### 9.1 MVP 캐릭터 팩

캐릭터 팩은 다음 논리 상태를 제공한다.

- 필수: Idle, Walk, Dragged, Thrown, Kick, Speak
- 권장: Chase, Dance, CarryCard, ClickReact, Special

권장 상태가 없으면 Idle 또는 Walk 프레임으로 대체한다. 필수 상태가 없으면 앱 시작을 막지 않고 내장 임시 기본 자산을 사용한다.

### 9.2 렌더링 규칙

- PNG 또는 WebP의 투명 배경 프레임을 사용한다.
- 기본 논리 캔버스는 256×256이며 실제 표시 크기는 설정에 따라 조정한다.
- 애니메이션별 프레임 수와 프레임 시간을 manifest에 정의한다.
- 이동 방향은 좌우 반전으로 처리할 수 있다.
- 액세서리는 캐릭터와 같은 좌표계의 별도 투명 레이어로 합성한다.
- 그림자, 말풍선과 카드 자산은 캐릭터 본체와 분리한다.

### 9.3 자산 준비 전 개발

- 충돌 영역과 발 위치는 이미지 크기가 아니라 manifest의 앵커 좌표로 정의한다.
- 임시 도형 또는 자리표시자 스프라이트로 모든 상태 전환을 시험할 수 있어야 한다.
- 완성 자산 교체 시 Rust 행동 로직을 수정하지 않아야 한다.

## 10. 기술 구조

### 10.1 런타임 구성

```text
Tauri 트레이·설정 UI
        ↓ command/event
Rust 애플리케이션 계층
  ├─ PomodoroService
  ├─ BehaviorScheduler
  ├─ DistractionMonitor
  ├─ InteractionController
  └─ SettingsService
        ↓ trait
Windows 인프라 계층
  ├─ ForegroundWindowSource
  ├─ WindowMinimizer
  ├─ IdleTimeSource
  ├─ MonitorLayoutSource
  └─ GlobalHotkey
        ↓ event
투명 펫 창·카드 창 렌더러
```

### 10.2 창 구성

- **펫 창:** 펫 주변 크기만 차지하는 무테·투명·항상 위 창. 펫 이동에 따라 창 자체를 이동한다.
- **카드 창:** 이미지 카드용 별도 투명 창. 최대 한 개만 생성한다.
- **타이머/설정 창:** 일반 Tauri 창이며 필요할 때만 표시한다.
- 전체 화면 크기의 투명 창을 상시 유지하지 않는다. 클릭 방해와 불필요한 GPU 합성을 줄이기 위함이다.

## 12. 오류 처리

- 대상 창이 사라지거나 바뀌면 발차기 연출은 취소하고 최소화하지 않는다.
- 권한 차이로 창을 제어할 수 없으면 앱을 종료하지 않고 해당 개입만 건너뛴다.
- 캐릭터 프레임이 없거나 손상되면 임시 기본 자산으로 대체한다.
- 설정 파일이 손상되면 복사본을 보관하고 안전한 기본값으로 시작한다.
- 전역 단축키가 충돌하면 설정 창에서 새 단축키를 요구한다.
- 오버레이 렌더러가 중단되면 Rust 서비스가 반복적으로 창을 최소화하지 않도록 모든 예약 개입을 취소한다.

## 17. 참고 원칙
