# 00. 프로젝트 브리프

## 제품명

미친감자 펫

## 개발 시작 조건

- 애플리케이션 코드 없음
- Tauri 프로젝트 없음
- 캐릭터 이미지와 애니메이션 없음
- 아이콘과 디자인 시스템 없음
- 테스트와 배포 설정 없음
- 제품 설계 문서만 존재

첫 실행부터 release 빌드까지 모두 24시간 범위에 포함한다. 완성 자산을 기다리지 않고 CSS 도형 또는 직접 만든 단순 placeholder로 구현한다.

## 한 문장 설명

화면 위를 돌아다니며 장난을 치고, 집중 시간에는 사용자가 지정한 방해 앱을 발로 차서 최소화하는 Windows 11 데스크톱 펫.

## 대상 사용자

- 컴퓨터 작업 중 작은 캐릭터와 상호작용하고 싶은 사용자
- 강압적인 차단 앱보다 유쾌한 집중 보조를 원하는 사용자
- 방해 앱과 개입 강도를 직접 통제하고 싶은 사용자

## 핵심 가치

1. 펫이 화면에 살아 있는 듯 행동한다.
2. 집중 방해를 캐릭터 연출로 부드럽게 끊는다.
3. 모든 개입은 사용자가 켜고 끌 수 있다.
4. 프로그램 실행, 파일 변경, 키 입력 수집을 하지 않는다.
5. 캐릭터 이미지는 코드 변경 없이 교체할 수 있다.

## MVP 핵심 사용자 흐름

### 평상시

1. 앱이 트레이에 상주한다.
2. 펫이 작업 영역 안에서 걷고 쉰다.
3. 사용자가 클릭하거나 드래그하면 반응한다.
4. 빠르게 놓으면 관성으로 날아가고 3초 안에 착지한다.

### 집중 중

1. 사용자가 집중 세션을 시작한다.
2. 앱은 등록된 방해 규칙과 현재 전경 창을 비교한다.
3. 같은 창이 유예 시간 동안 유지되면 펫이 경고한다.
4. 실행 직전에 대상이 여전히 같은지 다시 확인한다.
5. 발차기 충돌 프레임에 해당 창만 최소화한다.
6. 휴식, 일시정지, 대상 변경 또는 긴급 중지 시 개입을 취소한다.

## 기본 안전값

- 창 최소화 개입: 꺼짐
- 방해 규칙: 없음
- 비활동 경고: 꺼짐
- 장난 빈도: 낮음
- 자동 시작: 꺼짐
- 긴급 중지: `Ctrl+Shift+F12`

## 성공 지표

- 17시간 안에 핵심 집중 흐름이 데모 가능하다.
- 대상이 바뀐 뒤 잘못된 창을 최소화하는 사례가 없다.
- 긴급 중지가 300ms 수준으로 반영된다.
- 펫이 화면 밖으로 영구히 사라지지 않는다.
- 설정이 재실행 뒤 복원된다.
- release 빌드와 핵심 테스트가 통과한다.

## 개인정보 원칙

- 네트워크 전송 없음
- 분석 SDK 없음
- 키 입력 내용과 스크린샷 수집 없음
- 브라우저 방문 기록과 URL 접근 없음
- 창 제목은 메모리에서 규칙 대조 후 폐기
- 로그에는 실제 창 제목과 사용자 규칙 문자열을 기록하지 않음
